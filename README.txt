COMO SUBIR NO GITHUB E HOSTGATOR
─────────────────────────────────

1. GITHUB (backup)
   - Crie um repositório privado em github.com
   - Faça upload de todos os arquivos desta pasta
   - Isso serve como backup e controle de versão

2. HOSTGATOR (produção)
   - Acesse: hpanel.hostgator.com.br
   - Gerenciador de Arquivos → public_html
   - Faça upload de TODOS os arquivos
   - IMPORTANTE: mantenha a estrutura de pastas (imagens/, portfolio/, videos/)
   - Acesse seu domínio para verificar

SISTEMA DE MEMBROS
═══════════════════════════════════════════════════════

FLUXO DE VENDA:
1. Cliente clica "Comprar" no site
2. Modal PIX abre com QR Code e chave copia e cola
3. Cliente paga e manda comprovante no WhatsApp
4. Você confirma o pagamento
5. Abre Admin → Aba "Membros" → "+ Criar Membro"
6. Preenche nome, email e marca os produtos comprados
7. Sistema gera senha automática
8. Você copia as credenciais e manda no WhatsApp

PROTEÇÕES DO SISTEMA:
- Login por dispositivo + fingerprint
- 1 sessão ativa por vez
- Bloqueio após 3 tentativas erradas
- Marca d'água com nome do cliente nos ebooks
- Sem download, sem copiar texto, sem print
